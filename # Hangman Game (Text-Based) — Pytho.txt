# Hangman Game (Text-Based) — Python Mini Project

## 🎯 Objective
To design and implement a simple, text-based **Hangman Game** in Python
using only fundamental programming concepts taught in the first year of
a Computer Science Engineering course — such as loops, conditionals,
functions, strings, and lists — without relying on any external
libraries or advanced features.

## ✨ Features
- Randomly selects a word from a fixed list of 5 words every time you play.
- Player guesses the word one letter at a time.
- Displays the word progress using underscores (`_`) for hidden letters.
- Shows correctly guessed letters and wrongly guessed letters separately.
- Tracks and displays remaining attempts (maximum 6 wrong guesses allowed).
- Handles invalid input gracefully:
  - Empty input
  - More than one character
  - Numbers or symbols
  - Duplicate letters already guessed
- Accepts both uppercase and lowercase letters (e.g., `A` and `a` work the same).
- Displays a congratulation message when the player wins.
- Reveals the correct word when the player loses.

## 🧠 Concepts Used
- `random` module (`random.choice()`)
- `while` loop (main game loop and input validation loop)
- `if-else` conditional statements
- Strings and string methods (`.lower()`, `.strip()`, `.isalpha()`)
- Lists (word list, guessed letters list, wrong letters list)
- Functions (`choose_word()`, `display_word()`, `get_guess()`, `play_game()`)
- Basic `input()` and `print()` for interaction

## 📋 Requirements
- Python 3.x installed on your system
- No external/third-party libraries needed (only Python's built-in `random` module)

## ▶️ How to Run
1. Make sure Python 3 is installed.
2. Download the `hangman.py` file.
3. Open a terminal/command prompt in that folder.
4. Run the following command:
   ```bash
   python hangman.py
   ```
5. Start guessing letters one at a time until you win or run out of attempts!
